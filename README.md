# Sistema de gestão para salões (SaaS)

Esta pasta é o ponto de partida do projeto. Ela ainda não tem código: tem o **desenho** (o que o sistema faz, como guarda os dados, como calcula comissões e como protege os clientes), para o Claude Code construir com tudo já combinado.

## Como começar a construir
1. Abra esta pasta no Claude Code.
2. Escreva: **"Leia o CLAUDE.md e a pasta docs. Depois me explique, em português simples, o que vai fazer na Etapa 1 e peça minha confirmação antes de começar."**
3. Confirme, teste cada etapa na tela como se fosse uma usuária e diga o que está errado.

## O que tem aqui
- `CLAUDE.md`: regras que o Claude Code segue em toda conversa.
- `docs/01-escopo.md`: o que entra no primeiro lançamento e o que fica para depois.
- `docs/02-decisoes.md`: decisões já tomadas e o motivo.
- `docs/03-modelo-de-dados.md`: como o banco de dados guarda as informações.
- `docs/04-comissoes-e-assistentes.md`: como as comissões e os assistentes funcionam, configurável por salão.
- `docs/05-seguranca.md`: lista de segurança e LGPD.
- `docs/06-etapas.md`: ordem de construção, com o que precisa funcionar em cada etapa.

## Importante
- Valores e prazos nos documentos são **estimativas**. Confirmar com o contador.
- A stack (Next.js + Supabase + Vercel) é uma **proposta**. Pode ser trocada antes de a primeira linha de código ser escrita.
- Nada de copiar o Salon Soft: ele é só referência do que um salão precisa.
